# Memo · 酒馆版 1.0.12

安装地址：https://github.com/cszgezi-lab/Memo-ST

支持 SillyTavern 1.17.x–1.19.x。扩展管理中安装后，打开 Memo 的设置，填写总结、动态人设、向量或重排连接，再按需要开启运行。与旧版拾忆使用独立存储、连接和安装地址；同一聊天请只启用其中一个版本。

设置中的标签管理可提取或排除 XML 等正文块，不修改聊天原文。日志页提供日志、配置及当前聊天备份导出；API Key 不进入备份。存档按当前站点、浏览器、账户和聊天隔离。更换浏览器、设备或站点前，请导出需要的聊天备份。

实际记忆注入和动态人设替换支持 Chat Completion。文本生成接口保留原设定，可整理、管理和预览记忆。总结、人设和模型列表使用酒馆认证转发；向量、重排及非标准接口路径需服务允许浏览器 CORS。

浏览器下载提示只表示已派发，请确认文件实际保存。真实模型语义和 Android 实机效果需要分别验收。

主总结、修复复核及动态人设采用流式传输，收到完整回复并通过原有校验后才保存；中断和错误不会作为成功结果落地。已知渠道错误会尽早结束等待，恢复仍受现有次数上限、限流与冷却约束。主总结预设新增“破甲区”：反截断开关和可编辑破甲词；已取消头部及用户输入长填充，旧预设中的填充开关不再发送这两段文本，保存后生效。破甲词计入预算，工具参数与记忆完整性仍严格校验；这些选项不能保证解决服务商截断或限流。兼容工具及填充文本的 MIT 署名见 LICENSE.txt。
